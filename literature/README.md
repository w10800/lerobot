# CRP-VLA literature library

`papers/` contains downloaded primary-source PDFs. `manifest.tsv` records priority, role, source URL, local filename, and SHA-256. `notes/` contains human/Codex reading notes; copy `notes/TEMPLATE.md` for each paper.

Priority 1 establishes the model, one-step method, benchmark, and mathematical foundations. Priority 2 defines adjacent-work boundaries. Priority 3 is implementation and distillation background.

Downloaded PDFs are research inputs, not project findings. Claims used in code or writing must cite the source and note whether they have been locally reproduced.
